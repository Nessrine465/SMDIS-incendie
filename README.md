# SMDIS-incendie

## Suivi de l'avancement

L'avancement du projet est consultable en ligne : **https://smdis-progress-tracker.vercel.app**

Le site montre le pipeline de données, les moteurs de couverture et d'acheminement du personnel proposés, et la boucle d'apprentissage du modèle d'engagement. Cliquez sur une source pour voir ses liens et ce que nous en avons tiré.

## Où se trouve le travail

Pour l'instant, l'essentiel du travail se trouve sur la branche [`dev`](https://github.com/Nessrine465/SMDIS-incendie/tree/dev) : README du projet, énoncé et documents d'analyse.

Cette branche `main` ne contient pour l'instant que ce README.
